# 你们这些拉拉人穿的到底是什么 (Love Live! Costume Archive)

> 面向个人与考据爱好者的 **Love Live! 角色与衣装本地资料库**。  
> 专为解决准备 COSPLAY、画师取材或现场观演时“这套衣服叫什么、对应哪位角色、原始出处是哪儿”的考证痛点。

---

## 🌟 核心特性

- **🏛️ 企划历代阵容动态聚合**：
  - 动态聚合计算各企划成员人数（严禁前端硬编码），支持在“现役在籍”与“历代全员”之间自如切换；
  - 完整收录 **μ's (9人)**、**Aqours (9人)**、**虹咲学园 (13人)**、**Liella! (11人)**、**莲之空女学院 (102期至106期历代14人)** 以及 **いきづらい部！ (10人)**。
- **👘 角色专属衣装检视展台**：
  - 支持多角色同套主题（如全员打歌服）各自独立立绘、独立考据与独立核实；
  - 严谨区分手游卡面特态（**觉醒前生活服** vs **觉醒后舞台服**）以及**声优 Live 现场演出服**，支持多维精准筛选。
- **🛡️ 证据链强校验机制**：
  - 标记为“已核实（Verified）”的衣装必须具备查实属实的官方日文原名，并至少绑定一条带有效 HTTP/HTTPS 链接与出处的权威来源（后端硬校验拦截，杜绝虚假与杜撰）。
- **🔍 待识别暂存模式**：
  - 看到好看的服装但尚未考据出官方名称？允许先行录入图片并标记为“待识别”，严禁系统或用户编造假官方名，留待后续补全。
- **🎨 Codex 1.9 单画板工作台**：
  - 彻底摒弃粗暴的后台管理模板，以**三船栞子《决意之光》（決意の光）**夜间和风现代舞台为全站视觉定调；
  - 采用水平天际线顶栏、大图检视台（Image Stage）、胶片底片卷（Filmstrip）与全屏大图灯箱（Lightbox）。
- **💾 零外部依赖与本地安全备份**：
  - 纯本地离线运行（SQLite + 本地物理存储目录），数据资产完全物理隔离在 `data/` 目录中，代码更新升级永不覆盖用户数据；
  - 提供一键导出整库 ZIP 快照及安全还原（自动生成 `.bak` 副本）。

---

## 🛠️ 技术栈

* **前端**：Vite + React 19 + TypeScript + Tailwind CSS v4 + Lucide Icons
* **后端**：Node.js + Express + Multer (本地物理图片上传托管)
* **数据库**：SQLite (`better-sqlite3`) 单文件持久层（`data/archive.db`）
* **备份引擎**：`adm-zip` 原生快照解压与校验

## 🚀 快速启动

### 1. 环境准备
确保本机安装了 Node.js (>= 20) 与 pnpm。

### 2. 安装依赖
```bash
pnpm install
```

### 3. 一键启动本地服务
```bash
pnpm run dev
```
启动后在浏览器中访问：`http://localhost:5173`。

### 4. 运行全量验收测试 (AC-1 ~ AC-10)
```bash
pnpm test
```

### 5. 创建本地数据全量快照备份
```bash
pnpm run backup
```

## 📜 项目约定

1. 数据真实性优先：未核实或空数据保持空状态，严禁生成臆想或未证实的设定内容。
2. 涉及官方角色名、曲名、衣装原名严格保留日文官方规范写法。
3. 用户上传图片与 SQLite 数据库绝对不提交版本控制。
