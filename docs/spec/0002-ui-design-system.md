# 0002 - UI 设计系统：Codex 单画板迁移与《决意之光》舞台定调

## 背景与设计目标

为了让“Love Live! 衣装资料库”摆脱粗糙的传统 AI 模板感与平庸的后台表格感，本项目迁移 Codex 1.9 成熟的**单画板沉浸式桌面 UI 体系（Single-Canvas Composition）**，并以三船栞子在《决意之光》（決意の光）中的演出舞台视觉为全站核心美术风格进行定调。

---

## 视觉定调分析（参考图：三船栞子《决意之光》舞台）

参考图片提炼的核心视觉 DNA：
1. **夜幕舞台深邃底色**：深邃午夜蓝（`#080D1A` ~ `#0C1427`），营造身临演唱会现场的沉浸黑场氛围，衬托服饰的高清色彩。
2. **翡翠玉绿（Jade Accent）**：三船栞子官方代表色（`#36B898` / `#2DD4BF`），作为全站第一视觉锚点，用于选中态、高光按钮、品牌标识及“已核实”认证徽标。
3. **霓虹亚克力发光（Stage Neon & Acrylic）**：
   - 霓虹青蓝（`#00E5FF` / `#38BDF8`）：模拟舞台心形招牌与立柱灯管；
   - 舞台金（`#FBBF24`）：模拟和风华丽金丝刺绣与暖色聚光灯；
   - 舞台彩虹霓虹微光（Rainbow stage stripes）：作为局部悬停或点缀。
4. **材质工艺**：磨砂亚克力玻璃拟态（`backdrop-filter: blur(16px)`）、半透明导光细边框（`rgba(56, 189, 248, 0.18)`）与微发光阴影。
5. **文字排版**：无衬线现代屏显体为主，搭配优雅的日文斜切副标题（`title-jp`，倾斜 -6° ~ -11°）与角色名言微排版。

## 交互细节与验收标准（UI 专项）

1. **暗场高对比度与防刺眼**：背景虽为深黑蓝，但文字必须清晰可辨，对比度达到 WCAG AA 级别，绝不出现灰色文字贴在灰底上的脏乱感。
2. **高画质大图灯箱（Lightbox）**：点击任意衣装，瞬间唤起居中大图查看器，支持“适应视口 / 查看原始分辨率”，并配有毛玻璃模糊背景与可复查出处链接直跳。
3. **已核实权威感**：标记为“已核实”的衣装，卡片角标带有清晰的翡翠绿发光徽章（Shield Check），与“待识别”的半透明灰框形成明显视觉优先级差距。
