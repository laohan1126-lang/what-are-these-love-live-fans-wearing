## 2. Protected Features Verification

1. **Project & Character Switching**: `TopNav` open skyline scale (`01 虹咲学园 /13` .. `06 いきづらい部 /10`), bottom-line search input, and `名簿` (`MemberDrawer`) all switch projects, sub-units, active/graduated filters, and characters without data loss.
2. **Multi-Dimensional Filtering**: `STATUS` (`全卷 / 玉印已核实 / 待核实 / 待识名`), `ORIGIN` (`全出处 / 卡面 / 声优Live / 实穿对照`), and `全形态 / 觉醒后 / 觉醒前` filter costumes in real time.
3. **2D × 3D Folding-Screen Stage & Lightbox**: `#primary-action` cycles `双折并置 (2D×3D)` → `壱·绘卷 (2D)` → `弐·现世 (3D)`, and `#action-lightbox` opens `CostumeLightbox` (`qa/lightbox-open.png`) with 150% zoom and multi-angle frame navigation.
4. **Add / Edit / Curate / Backup**: `#action-add`, `#action-edit`, `#action-curate`, and `文庫備份` (`BackupModal`) remain fully operational.
